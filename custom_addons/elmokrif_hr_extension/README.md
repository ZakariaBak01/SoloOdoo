# EL MOKRIF HR Extension

This Odoo 17 addon provides the first HR delivery slice for EL MOKRIF:

- dedicated HR employee/officer/manager roles;
- configurable contract-expiry activities with retry-safe creation;
- server-side protection for approved leave requests;
- employee self-service leave ownership checks;
- confidential employee appraisal workflow with protected completion and audited reopening.

The addon deliberately does not add employee-to-chantier access rules, payroll,
expenses, timesheets, documents, or calendar synchronization. Those integrations
need separate business and security decisions so HR private data cannot broaden
chantier visibility accidentally.
